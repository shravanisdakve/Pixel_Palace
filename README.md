# 🎮 Pixel Palace Arcade

> **Curated Web Arcade Platform & Mini-Games Collection**

![Pixel Palace Status](https://img.shields.io/badge/Status-Production%20Ready-success?style=for-the-badge)
![Tech Stack](https://img.shields.io/badge/Built%20With-HTML5%20%7C%20CSS3%20%7C%20JS-blueviolet?style=for-the-badge)
![Developer](https://img.shields.io/badge/Developer-Shravani%20Dakve-ff00ff?style=for-the-badge)

**Pixel Palace** is a curated web arcade platform featuring over **44+ browser-based mini-games** across 7 distinct categories. It features a custom retro-arcade interface, 2D story illustrated cover artwork, local high-score leaderboards, search filtering, and responsive mobile navigation.

## ✨ Key Features

* 🕹️ **44+ Playable Mini-Games**: Instant in-browser play with zero installation or downloads required.
* 🎨 **Story-Driven Illustrated Cover Art**: Unique 2D illustrated story covers designed for each game.
* 🏆 **Local Leaderboards & History**: High-score tracking via `ScoreManager` and recently played game history.
* 🔍 **Instant Search & Category Filtering**: Filter games by `All`, `Action`, `Puzzle`, and `Classic`.
* 📱 **Mobile Drawer & Responsive Navigation**: Smooth touch-optimized navigation with drawer overlay.
* 🔊 **Web Audio Sound Effects**: Retro arcade SFX generated using Web Audio API (`sound_manager.js`).

## 🚀 How to Run Locally

Simply clone the repository and open `index.html` in any web browser!

```bash
# Clone the repository
git clone https://github.com/Shravanidakve/Pixel_Palace.git

# Navigate into directory
cd Pixel_Palace

# Start local server (optional)
python3 -m http.server 8000
```

Open `http://localhost:8000` in your browser.
